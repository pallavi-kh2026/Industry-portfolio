# Pallavi Modern React Portfolio

A clean, beginner-friendly React portfolio with light/dark mode.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Easy customization

1. Edit personal text in `src/App.jsx`.
2. Edit project information in `src/data/projects.js`.
3. Replace `public/profile-placeholder.svg` with your photo.
4. Add your resume as `public/resume.pdf`.
5. Replace `your-email@gmail.com` with your email.
6. Replace placeholder GitHub/demo links with your real project links.

## Main React concepts used

- Components
- Props
- useState
- React Router
- map()
- Conditional rendering
- CSS responsive design

The project deliberately keeps the code straightforward so each part can be explained in an interview.
